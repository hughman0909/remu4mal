# remu4mal

## What is remu4mal?
remu4mal stands for Rust EMUlator FOR MALware.
Currently, this is just a x86 emulator. 
My plan for this is to make an emulator which can run a malicious file and visualize, deobfuscate and unpack it.

Current goal is 
1. to support as many as x86 instructions
2. to get used to coding rust
3. implement x64 instructions

## Usage
```
$ cargo run -- sample.bin
```
